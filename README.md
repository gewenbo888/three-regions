# Three Regions

Bilingual comparison of California, Guangdong (incl. Hong Kong & Macau), and Nigeria.

[![Live Demo](https://img.shields.io/badge/demo-three--regions.vercel.app-amber)](https://three-regions.vercel.app)

## Overview

A bilingual (English / Chinese) editorial-style single-page site comparing three global regions across eight dimensions:

1. **Overview** -- geography, population, GDP
2. **Technology** -- innovation ecosystems
3. **Industry** -- economic structure and key sectors
4. **Lifestyle** -- daily life and social patterns
5. **Cost of Living** -- housing, food, transport
6. **History** -- key historical milestones
7. **Culture** -- traditions, arts, identity
8. **Interconnections** -- how the three regions relate

Each section features animated bar charts and data-driven comparisons.

## Design & Tech

- **Stack:** Single HTML file, vanilla JavaScript, animated charts
- **Aesthetic:** Editorial magazine layout on warm parchment background
- **Color System:** Amber (California) / Vermillion (Guangdong) / Green (Nigeria)
- **Typography:** Libre Baskerville (English) + Noto Serif SC (Chinese)
- **Deployment:** Vercel
